# Skinstric AI

[View Live Demo](https://skinstric-azure.vercel.app)

<img width="789" height="603" alt="skinstric" src="https://github.com/user-attachments/assets/01ddc38a-af7f-42e1-b956-c3c22e668b73" />


An AI-powered image analysis application built with Next.js and TypeScript. Users can submit a photo through image upload or camera capture.

## Features

- Image upload for submitting an existing photo.
- Camera capture for taking a photo within the app.
- API integration for processing images and displaying analysis results.

## Tech Stack

- Next.js
- React
- TypeScript
- REST APIs
- Vercel deployment

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Breanna47/skinstric.git
cd skinstric
```

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
